# Security Policy

## Reporting a vulnerability

Please do NOT open a public issue for security problems.

Use GitHub's private vulnerability reporting instead:
https://github.com/fxjrin/soroscan/security/advisories/new

You will get an initial response within 72 hours. Coordinated disclosure is appreciated; credit is given in the advisory unless you prefer otherwise.

## Scope

- The Soroscan web application and any Soroscan-operated services
- Rendering of hostile on-chain data (XSS via memos, asset metadata, contract meta, stellar.toml, and similar)

Issues in the Stellar protocol, Horizon, Stellar RPC, or third-party providers should be reported upstream to their maintainers.
